## What's changed

Game Mode fixes apply to both APK variants. Head tracking remains an opt-in
feature of the signed debug preview used for Pixel testing. For that preview,
open this version's successful [Android CI run](https://github.com/Ripthulhu/librepods/actions/workflows/ci-android.yml)
and download the `apk-debug` artifact. The attached `LibrePods.apk` is the normal
release build and does not enable head tracking.

- Smooth out Game Mode playback by reducing repeated native memory-map scans and keeping the controller's existing packet permissions and retry timeout. Debug and release builds now use the same settings as the working Pixel preview.
- Fix Game Mode getting stuck or showing an incorrect failure during pause, resume and cleanup. Status now follows the current audio stream, and restoration waits safely for unrelated controller commands to finish.
- Keep head tracking running when the Pro 3 sensor counter wraps. The same clock-checked handling now applies to playback and calibration captures, while genuine resets still invalidate the stream.
- Improve delivery of the 100 Hz motion stream. A bounded two-report handoff retains short Bluetooth bursts without blocking the source or accumulating old movement data.
- Give tracking startup time to receive its first valid attitude before falling back. Retain a small timing summary after a session ends to help diagnose remaining gaps; no raw pose history or per-packet logging is enabled.

## Validation

On the Pixel with Game Mode off, the three-minute silent check received about
99.2 fresh motion reports per second and delivered 99.1 to the app, compared
with about 90 previously. Tracking crossed a counter wrap without fallback or
a pose fault. A separate six-minute run also crossed the wrap successfully.
Plex playback was confirmed smooth, with anchored head tracking and clean audio.

Game Mode's listening comparison completed without the previous extra hitches,
and its switch followed both changes correctly. AAC-ELD/PCM32, saved calibration
and volume behavior were preserved. Focused app/core tests, native regression
and sanitizer checks, build and lint accompany these changes; CI runs the full
Android verification before publishing the APK.

These tests do not establish all-day stability or measured acoustic latency.
The 100 Hz result applies with Game Mode off; Game Mode can reduce the delivered
motion rate. Native Atmos head tracking is still under development and is not
enabled in this release. The existing Android spatial-audio path remains available.
