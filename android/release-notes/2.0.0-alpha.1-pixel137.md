## What's changed

- **Head tracking beyond the temporary check.** The DEBUG preview adds a normal
  Head Tracking switch after calibration. LibrePods' existing background service
  owns the sensor, so navigating away does not end an enabled session. Android's
  reporting request starts and stops this motion source; idle playback does not
  keep the AirPods streaming unnecessary motion data.
- **Keep a valid calibration.** Setup saves its validated axes privately for the
  exact AirPods, firmware and full reported bud role. A different source cannot
  borrow those axes, and old sensor timestamps are never restored. Recalibrate
  stays available; a failed save offers a clear retry instead of claiming success.
- **Recover from brief missing reports.** A short, forward-clock gap now primes
  fresh rate measurements without resetting the orientation reference. Clock
  resets, invalid poses and long gaps still stop tracking safely.
- **Respect Off and temporary interruptions.** Calls, recording, calibration,
  changed roles and root loss release the provider without changing the saved
  native choice. Automatic recovery never turns an Off preference back on. Old
  requests lose ownership when a newer choice arrives, and native Off is handled
  independently of potentially blocked Bluetooth source cleanup.

Head tracking is still a **DEBUG preview** pending a real-motion listening check.
Fixed spatial audio remains the supported option in the regular release APK.
No codec, PCM32 format, volume curve, audio buffer or Bluetooth connection setting
is changed by this update. The temporary diagnostic check retains its 30-second
limit and restores its starting preference.

## Validation

The recorded successful calibration was replayed through the compiled converter
and sensor-report codec: 548 valid poses from 550 samples, with one initial prime
and one brief-gap re-prime, no reference restart and no invalid pose.

Automated checks cover profile identity and corruption, save failure, native
discovery before enabling, durable Off, external choices, reporting idle,
cancellation, source ownership, blocked cleanup and the setup/settings screens.
CI checks Android lint, the signed full AAC-ELD/PCM32 package and native audio tests.

Real AirPods motion driving active Android spatial rendering, provider recovery on
hardware, and acoustic latency remain unverified. No new listening test was run
for this build. Dolby Atmos work is separate.
