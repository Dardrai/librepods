## What's changed

- **Readable spatial-audio setup.** The root-access explanation sits below the
  title instead of taking its width and wrapping it into a vertical column.
- **Live spatial-audio status.** The row refreshes automatically when the root
  helper connects or a setting changes. An already granted connection no longer
  leaves an obsolete Allow root access message on screen.
- **Safer motion calibration.** Debug captures record which bud is primary and
  stop if that role changes, preserving a consistent sensor frame for analysis.

The AAC-ELD/PCM32 encoder, volume settings and Bluetooth connection are unchanged.
Fixed spatial audio continues to use Android's native renderer for supported
surround media. Real Pro 3 head tracking is still being calibrated.

## Validation

UI regression coverage exercises automatic root readiness and settings refresh,
and checks the title and description at narrow widths and enlarged text sizes.
Motion tests verify owner-specific cleanup when either primary role changes.
The signed full-codec APK is published only after the complete CI checks pass.
