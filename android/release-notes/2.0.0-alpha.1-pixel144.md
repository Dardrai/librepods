## What's changed

- Correct Game Mode failure messages. An unsuccessful activation no longer says that turning Game Mode off failed. The quick panel shows known failures while keeping taps immediate, and the full settings switch remains visible after support has been established.
- Add bounded head-tracking diagnostics for the first fallback decision and successful sensor-rate writes. Source-gap measurements exclude time between tracking sessions and mark gaps spanning a rate change as mixed rather than blaming the slower rate.

This is a diagnostic preview. Pixel143 delivered about 99 Hz in the short quiet
and audible checks, and the listening check confirmed smoother movement and
stops. The three-minute run nevertheless developed source gaps and fell back
to the 50 Hz request. Sustained 100 Hz and Game Mode's steady-playback hitches
remain under investigation.

AAC-ELD/PCM32, receiver buffer targets, radio packet policy, clock correction,
freshness limits, saved calibration and volume behavior are unchanged. No
per-packet logging is enabled.

## Validation

152 focused tests passed, including Game Mode transitions, quick-panel
interaction, motion-rate ownership and calibration conversion. App and core
lint passed. Device installation and controlled timing comparisons are the
next checks; this release does not claim a measured acoustic latency reduction.
