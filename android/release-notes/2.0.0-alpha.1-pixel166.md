## What's changed

- Enable Android's native spatial audio, calibration, and head tracking for supported AirPods Pro 3 connections in the regular LibrePods release.
- Include the calibrated motion interface and Pixel Dolby control client in the standard APK. A companion signed with the LibrePods key can use the same calibration and Bluetooth receipt timestamps.
- Keep the computed calibration result available to diagnostics if the profile cannot be saved.

## Spatial playback

The Pixel Dolby decoder is installed separately. The private Tidal module uses
the regular LibrePods APK for calibrated motion. On a Pixel 10 Pro XL, the
motion interface was checked with Tidal Atmos seeks and track changes, and with
Android's native 7.1 head tracking in Plex.
