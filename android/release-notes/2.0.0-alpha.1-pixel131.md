## What's changed

- **Simpler Contact section.** GitHub opens this repository directly. Removed
  the email entry and composer; the app offers no Discord contact entry.
- **Complete permission setup.** Grant All includes microphone access, uses
  Health Connect's permission screen when available, and opens Android's overlay
  settings instead of silently skipping that request.
- **Reliable permission prompts.** Keep the request sequence through redraws
  and screen recreation, prevent overlapping dialogs, and continue after an
  optional permission is denied. Nearby Devices remains the only requirement
  for completing onboarding.
- **Optional root or Shizuku setup.** Onboarding offers the same Bluetooth
  access setup as Settings. Explicit setup can authorize LibrePods' root helper
  with Shizuku as a fallback; opening or resuming the page does not request a
  fresh root grant. Returning after starting Shizuku refreshes the connection.

AAC-ELD/PCM32, the Bluetooth identity module and saved AirPods settings are
unchanged. This update does not reset existing users' permissions or onboarding.

## Validation

Regression tests exercise Contact's browser link, permission ordering,
recomposition and recreation, optional denials, microphone access, Health
Connect's contract, overlay return and privileged-helper lifetime. Android CI
runs tests, lint and signed full-codec package verification before publishing.
Robolectric test workers use a bounded heap and restart between batches so the
full suite can finish without accumulating every framework sandbox in one JVM.
