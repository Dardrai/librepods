## What's changed

- **Spatial audio stays off when switched off.** Android reports its current
  renderer as disabled when the selected device's spatial setting is off.
  LibrePods now accepts that expected transition instead of undoing it.
- **Off devices can be enabled again.** The control distinguishes a device
  preference from the renderer's current state, so Off does not disable its
  own switch or incorrectly ask you to enable Android's system setting.
- **Honest system-setting status.** If Android's system-wide renderer is
  independently disabled, LibrePods preserves your per-device choice and
  directs you to system settings without changing the global setting.

The Pixel133 text-layout and automatic root-status fixes are retained. No
Bluetooth restart, volume adjustment or codec change is part of this update.

## Validation

Regression tests model Android's actual engine state during On → Off → On,
verify exact per-device writes without rollback, and cover system settings
changing during a request. The UI also checks that an off device remains
writable. CI validates the complete signed AAC-ELD/PCM32 APK before publishing.
