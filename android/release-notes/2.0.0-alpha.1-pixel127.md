## What's changed

- **More reliable case returns.** Correctly acknowledge AirPods settings indications
  instead of closing the active settings channel. Reads and writes can finish on
  the existing connection. This fixes the captured disconnect sequence that
  occurred shortly after taking the buds out of the case.
- **Keep the call profile connected.** Avoid the malformed legacy battery exchange
  sent by AirPods Pro 3 during hands-free setup on Android 17. Battery levels remain
  available through LibrePods' normal AirPods protocol.
- **Renaming now has a clear finish.** The Name screen has a visible Done button and
  keyboard Done action. Names are sent once when submitted, rather than while typing.
- **Show the name actually saved on the buds.** Wait for fresh AirPods name readback,
  refreshing the settings connection when needed. The settings page updates without
  a case cycle. Failed verification keeps the draft open for retry; Unicode names
  are validated against the device's 64-byte limit.

## Checked on the Pixel

- Repeated case returns stayed connected, with steady loudness and clean playback.
- Phone calls worked in both directions, including mute, hang-up and return to music.
- Two name changes were confirmed from the AirPods in about half a second each,
  without restarting the audio or call connection.
- AAC-ELD/PCM32, pause/resume and listening-mode stem controls remain working.
  This release does not change the native encoder or volume behavior.

The call-profile compatibility change currently targets AirPods Pro 3 on Android 17.
Kettu calling and extended soak testing were not repeated for this release.
